# Administrator — дистрибутивы

**Тестовая версия для Windows: 1.0.10-rc.1 / test.2.**

[Скачать установщик Windows x64](https://github.com/dbzubov/administrator-releases/releases/download/windows-v1.0.10-rc.1-test.2/Administrator-1.0.10-rc.1-windows-x64-test.2-setup.exe) · [Описание релиза и SHA-256](https://github.com/dbzubov/administrator-releases/releases/tag/windows-v1.0.10-rc.1-test.2) · [Все версии](https://github.com/dbzubov/administrator-releases/releases)


Локальное приложение для работы с проектами, задачами, материалами,
встречами и рабочими документами.

Administrator помогает готовить инструкции со скриншотами, итоги встреч,
ПМИ, ТКП и план-графики. Проекты и результаты хранятся на компьютере
пользователя. Регистрация в Administrator не требуется.

Для функций AI нужен собственный API-ключ VseGPT и средства на балансе
провайдера. При обработке выбранные данные отправляются в VseGPT. https://vsegpt.ru/

## Скачать и установить

1. Откройте раздел **Releases** этого репозитория.
2. Выберите версию, прочитайте изменения и ограничения.
3. В блоке **Assets** скачайте `Administrator-…-windows-x64-…-setup.exe`.
4. Закройте Administrator и запустите установщик; подтвердите запрос администратора.
5. Закройте установщик и запустите **ProjectAdmin** из меню «Пуск» обычным способом.

Первая Windows-версия предназначена для тестирования. Поддерживаются Windows 10
(сборка 19041+) и Windows 11 x64; ARM и 32-разрядная Windows пока не проверяются.
Программа устанавливается в `C:\Program Files\ProjectAdmin`; установщик требует
прав администратора. Само приложение запускается обычным пользователем. При отсутствии Microsoft
Edge WebView2 установщик запускает официальный установщик Microsoft; для него
нужен интернет. На корпоративных ПК установку Runtime может выполнять IT-служба.

Тестовый установщик пока не подписан сертификатом издателя: Windows может
показать предупреждение SmartScreen. Проверяйте источник и SHA-256; на рабочем
компьютере согласуйте установку с IT, если этого требуют правила компании.

## Обновления и данные

Обновления устанавливаются только вручную через Releases. Приложение не проверяет,
не скачивает и не устанавливает новые версии автоматически. Закройте приложение и запустите новый установщик с разрешением администратора.
Затем открывайте ProjectAdmin под своей обычной учётной записью Windows.

Данные находятся в `%LOCALAPPDATA%\Administrator Prototype`, отдельно от программы.
Закройте приложение и скопируйте весь этот каталог перед установкой тестовой версии.
API-ключ хранится в диспетчере учётных данных Windows, читается один раз при запуске
и затем используется из памяти. Ключ не входит в установщик и резервную копию базы.
Удаление приложения оставляет локальные проекты; удаление ключа доступно в настройках.

## Сообщить об ошибке

Создайте обращение в **Issues**: версия Administrator и Windows → шаги → ожидаемый
и фактический результат → текст ошибки/скриншот. Укажите включён ли VPN.
Не прикладывайте ключи, пароли, личные данные и конфиденциальные материалы.

Здесь публикуются установщики, контрольные суммы SHA-256 и описания изменений.

## Переход с первой Windows-сборки

Перед установкой **test.2** удалите прежнюю **Administrator test.1** через
«Параметры → Приложения → Установленные приложения» под той учётной записью,
где использовалась программа. Это удаляет программу, сохраняя каталог проектов
и ключ. Не удаляйте `%LOCALAPPDATA%\Administrator Prototype` вручную.
Затем установите test.2 в Program Files. Автоматического запуска из установщика
нет: открывайте ProjectAdmin из меню «Пуск» под своей обычной учётной записью.

Если интерфейс не загрузился, примерно через 45 секунд появится код ошибки.
Файл диагностики: `%LOCALAPPDATA%\Administrator Prototype\diagnostics\startup.json`.
Он содержит только этапы запуска/версии/код ошибки, без ключей и содержимого проектов.

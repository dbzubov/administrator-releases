# Administrator — дистрибутивы

Локальное приложение для работы с проектами, задачами, материалами,
встречами и рабочими документами.

Приложение помогает готовить инструкции со скриншотами, итоги встреч,
ПМИ, ТКП и план-графики. Проекты и результаты хранятся на компьютере
пользователя. Регистрация в Administrator не требуется.

Для функций AI нужен собственный API-ключ VseGPT и средства на балансе
провайдера. При обработке выбранные данные отправляются в VseGPT.

## Скачать и установить

1. Откройте раздел Releases этого репозитория.
2. Выберите нужную версию и прочитайте описание изменений.
3. В блоке Assets скачайте установщик для своей операционной системы.
4. Закройте Administrator, если приложение уже запущено.
5. Запустите установщик и следуйте подсказкам.

Первая Windows-версия предназначена для тестирования.
Поддерживаются Windows 10 и Windows 11, архитектура x64.

## Обновления

Все обновления устанавливаются вручную через Releases.
Приложение не скачивает и не устанавливает их автоматически.

При обновлении используйте ту же учётную запись Windows.
Перед установкой тестовых версий сохраняйте резервную копию
важных данных.

## Сообщить об ошибке

Создайте обращение в разделе Issues и укажите:

- версию Administrator и Windows;
- действия перед ошибкой;
- ожидаемый и фактический результат;
- текст ошибки и, по возможности, скриншот.

Не прикладывайте API-ключи, пароли, персональные данные
и конфиденциальные материалы.

## Содержимое репозитория

Здесь публикуются установщики, контрольные суммы SHA-256
и описания изменений. Исходный код приложения хранится отдельно.

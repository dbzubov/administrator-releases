# Administrator — дистрибутивы

**Тестовая версия для Windows: 1.0.10-rc.1 / test.3.**

[Скачать установщик Windows x64](https://github.com/dbzubov/administrator-releases/releases/download/windows-v1.0.10-rc.1-test.3/Administrator-1.0.10-rc.1-windows-x64-test.3-setup.exe) · [Описание релиза и SHA-256](https://github.com/dbzubov/administrator-releases/releases/tag/windows-v1.0.10-rc.1-test.3) · [Все версии](https://github.com/dbzubov/administrator-releases/releases)


Локальное приложение для работы с проектами, задачами, материалами,
встречами и рабочими документами.

Administrator помогает готовить инструкции со скриншотами, итоги встреч,
ПМИ, ТКП и план-графики. Проекты и результаты хранятся на компьютере
пользователя. Регистрация в Administrator не требуется.

Для функций AI нужен собственный API-ключ VseGPT и средства на балансе
провайдера. При обработке выбранные данные отправляются в VseGPT. https://vsegpt.ru/

## Скачать и установить

1. Откройте раздел **Releases** этого репозитория.
2. Выберите версию, прочитайте изменения и ограничения.
3. В блоке **Assets** скачайте `Administrator-…-windows-x64-…-setup.exe`.
4. Закройте приложение и запустите установщик под своей обычной учётной записью.
5. Откройте «ProjectAdmin (для пользователя)» из меню «Пуск», затем **Настройки AI**.

Первая Windows-версия предназначена для тестирования. Поддерживаются Windows 10
(сборка 19041+) и Windows 11 x64; ARM и 32-разрядная Windows пока не проверяются.
Установка **Windows test.3** выполняется без запроса администратора в
`%LOCALAPPDATA%\Programs\ProjectAdmin`. Для записи в Program Files права
администратора по-прежнему нужны; пользовательская сборка туда не устанавливается.
Если отсутствует Microsoft Edge WebView2, официальный bootstrap Microsoft пытается
установить Runtime для текущего пользователя; нужен интернет. Если корпоративная
политика запрещает установку или запуск, обратитесь к ИТ: сборка не изменяет политики
Windows и не отключает защиту.


Тестовый установщик пока не подписан сертификатом издателя: Windows может
показать предупреждение SmartScreen. Проверяйте источник и SHA-256; на рабочем
компьютере согласуйте установку с IT, если этого требуют правила компании.

## Обновления и данные

Обновления устанавливаются только вручную через Releases. Закройте программу и
запустите новый пользовательский установщик под той же учётной записью Windows.
Фоновых проверок, скачивания и установки обновлений нет.

Данные находятся в `%LOCALAPPDATA%\Administrator Prototype`, отдельно от программы.
Закройте приложение и скопируйте весь этот каталог перед установкой тестовой версии.
API-ключ хранится в диспетчере учётных данных Windows, читается один раз при запуске
и затем используется из памяти. Ключ не входит в установщик и резервную копию базы.
Удаление приложения оставляет локальные проекты; удаление ключа доступно в настройках.

## Сообщить об ошибке

Создайте обращение в **Issues**: версия Administrator и Windows → шаги → ожидаемый
и фактический результат → текст ошибки/скриншот. Укажите включён ли VPN.
Не прикладывайте ключи, пароли, личные данные и конфиденциальные материалы.

## Переход на пользовательскую test.3

- **test.1:** удалите старую пользовательскую Administrator через «Установленные
  приложения» под исходной учётной записью. Папку данных и сохранённый ключ не удаляйте.
- **test.2:** общая копия в Program Files не удаляется автоматически и не блокирует
  пользовательскую установку. Её удаление может потребовать ИТ. Пользуйтесь новым
  ярлыком **ProjectAdmin (для пользователя)** или запускайте
  `%LOCALAPPDATA%\Programs\ProjectAdmin\Administrator.exe`.
- Обновления пользовательской test.3 устанавливаются поверх прежней пользовательской
  копии. Программа не переносит данные из другой Windows-учётной записи.

Если интерфейс не загрузился, файл диагностики:
`%LOCALAPPDATA%\Administrator Prototype\diagnostics\startup.json`.
Он содержит этапы запуска/версии/тип ошибки, без ключей и содержимого проектов.
